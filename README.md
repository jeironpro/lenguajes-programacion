# lenguajes-programacion

## 📌 Descripción
Este repositorio contiene aprendizaje de los lenguajes de programación que he ido aprendiendo.
Los lenguajes son Java, JavaScript y Python.
El aprendizaje de los lenguajes se ha realizado en diferentes instituciones como Infotep (Instituto Nacional de Formación Técnico Profesional de la República Dominicana y el Instituto de Tecnologías de la Información y la Comunicación de Barcelona).
Se ha completado con aprendizaje teórico y práctico usando OpenAI ChatGPT.
